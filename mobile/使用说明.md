# 校园课表 iOS 1.1 构建包

这是源代码和构建配置，不是已编译或已签名的 IPA。尚未进行 Xcode 编译、iOS 模拟器或 iPhone 真机测试。

包含 PDF 单双周跨行及分段解析修复、离线课表资源、文件导入、本机分享和课程提醒。工程最低系统 iOS 15；构建要求 Node.js 22+、macOS、Xcode 26+。

## 使用 GitHub 云端 Mac 编译

1. 建立用于 iOS 的仓库，把本目录的内容放到仓库根目录，包括 `.github/workflows/ios.yml`。
2. 打开 Actions，选择 Build iOS unsigned package，点击 Run workflow。
3. 成功后，在 Artifacts 下载 CampusSchedule-iOS-unsigned，解压得到 CampusSchedule-unsigned.ipa。
4. 该 IPA 未签名，不能直接点击安装。仍需合法可用的苹果签名证书与对应描述文件，或在 Mac 的 Xcode 中用自己的开发团队完成设备安装。

工作流仅手动触发，不发布 App Store 或 TestFlight。私有仓库的云端构建会使用 GitHub Actions 额度；是否产生费用取决于账号额度与计费设置。此配置已做静态检查，但未实际运行云端构建。

## 使用自己的 Mac

在本目录执行 `bash scripts/build-ios.sh`，可生成未签名 IPA。实际安装到自己的 iPhone：先完成依赖安装和 `npx cap sync ios`，再打开 `ios/App/App.xcodeproj`，在 Signing & Capabilities 选择自己的 Team，必要时修改 Bundle Identifier，连接 iPhone 并使用 Xcode Run。签名与设备开发权限必须按 Xcode 的提示完成。

向其他人分发或上架还需对应的苹果开发者资格、签名和分发流程。本包未包含个人课表、安卓密钥、苹果账号或签名证书。
